## 🔬 How It Works
This engine models short-term cognitive "thoughts" as a **Complex Quantum Wave Packet ($\psi$)** evolving through time using a discrete 2D Laplacian operator. 

Instead of moving across a flat network, the thought encounters an **Ultra-Dense Memory Assembly** at the center of the grid, which creates a mathematical gravity well. The code applies a **Schwarzschild-derived Time Dilation Metric** to dynamically scale down the time-step ($\Delta t$) based on spatial distance, forcing the thought field to warp, shear, and orbit around the memory core.
